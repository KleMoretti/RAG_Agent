# RAG Agent System

This project implements a Retrieval-Augmented Generation (RAG) Agent system. The aim is to provide a framework for building agents that can retrieve and generate information based on a given context.

## Project Structure

- `data/`: Contains the datasets used for training and evaluation.
- `src/`: Source code for the RAG Agent system.
- `tests/`: Unit and integration tests.
- `scripts/`: Scripts for data ingestion and evaluation.
- `notebooks/`: Jupyter notebooks for experiments.
- `docs/`: Documentation files.
