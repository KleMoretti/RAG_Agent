## 6. 使用示例

### 场景 1: 上传技术文档
```
1. 用户上传 "API文档.pdf"
2. 系统处理并分块
3. 用户询问: "这个API支持哪些认证方式？"
4. AI 基于文档内容回答
```

### 场景 2: 上传代码文件
```
1. 用户上传 "main.py"
2. 系统提取代码内容
3. 用户询问: "这段代码的主要功能是什么？"
4. AI 分析代码逻辑并解释
```

### 场景 3: 批量文件上传
```
1. 用户上传 "报告1.txt"
2. 用户上传 "报告2.txt"
3. 用户询问: "对比这两份报告的差异"
4. AI 综合两个文件内容进行对比分析
```

## 7. 支持的文件类型

| 类型 | 扩展名 | 说明 |
|------|--------|------|
| 文本 | .txt, .md | 纯文本文件 |
| 文档 | .pdf, .doc, .docx | 办公文档 |
| 代码 | .py, .js, .ts | 编程代码 |
| 数据 | .json, .csv | 结构化数据 |

---

## 8. 限制和建议

- 📏 **文件大小**: 最大 10MB
- 📝 **文件类型**: 主要支持文本类文件
- 🔒 **安全性**: 文件内容仅用于当前会话
- 💾 **存储**: 文件保存在 data/raw 目录
- 🔍 **索引**: 自动向量化并添加到知识库
