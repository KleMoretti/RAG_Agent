# 工艺流程选择功能使用指南

## 功能概述

工艺流程管理系统现已支持 **6 种标准钢铁生产工艺路线** 的动态切换，用户可以根据实际场景选择不同的工艺流程进行可视化展示和参数查看。

## 支持的工艺流程

### 1. 高炉—转炉（BF→BOF）长流程
- **碳排放**: 1.8-2.5 t CO₂/t 钢
- **节点数**: 8 个工艺节点
- **适用场景**: 大型综合钢厂，原料为铁矿石、焦炭，适合百万吨级/年产线
- **优势**: 产能大、成熟稳定
- **劣势**: 碳排放较高、焦炭依赖

**主要工序**:
1. 原料准备（破碎/筛分/配料）
2. 炼焦（焦炉）
3. 烧结
4. 高炉炼铁
5. 转炉炼钢（BOF）
6. 炉外精炼（LF/RH）
7. 连续铸造
8. 轧制与热处理

### 2. 废钢电炉（EAF）短流程
- **碳排放**: 0.3-0.9 t CO₂/t 钢
- **节点数**: 4 个工艺节点
- **适用场景**: 中小型钢厂、mini-mill，适合废钢丰富区域
- **优势**: 低碳排放、弹性生产
- **劣势**: 电价敏感、废钢质量依赖

**主要工序**:
1. 废钢回收与准备
2. 电弧炉熔炼（EAF）
3. 炉外精炼（LF/VD）
4. 连铸→轧制→热/冷处理

### 3. 直接还原（DRI）→ 电炉
- **碳排放**: 0.4-1.0 t CO₂/t 钢
- **节点数**: 4 个工艺节点
- **适用场景**: 天然气/氢气资源充足或追求低碳产品
- **优势**: 低碳路线、合金与特种钢可控性好
- **劣势**: 气源依赖、投资大

**主要工序**:
1. 球团/精矿制备
2. DRI 直接还原（竖炉/旋转炉）
3. 电弧炉熔化（含 DRI/HBI）
4. 精炼→连铸→轧制

### 4. COREX / FINEX 熔融还原
- **碳排放**: 1.2-2.0 t CO₂/t 钢
- **节点数**: 3 个工艺节点
- **适用场景**: 希望替代/补充高炉产能、减少焦炭依赖的中大型厂
- **优势**: 减少焦炭依赖、回收副产煤气
- **劣势**: 技术复杂

**主要工序**:
1. 块矿/球团制备
2. 熔融还原反应器（COREX/FINEX）
3. 炼钢→精炼→连铸→轧制

### 5. 真空/特殊精炼路线（高端钢种）
- **碳排放**: 0.5-2.5 t CO₂/t 钢
- **节点数**: 3 个工艺节点
- **适用场景**: 高端市场/特种钢厂，要求成分与夹杂物严格控制
- **优势**: 超净钢、精度高
- **劣势**: 产能相对小、成本高

**主要工序**:
1. 初次熔炼（BF/BOF/EAF）
2. 真空脱气（VD/VOD）
3. 精确合金添加与微量元素控制

### 6. 连铸—热轧一体线（CC–HSM）
- **碳排放**: 0.4-1.2 t CO₂/t 钢
- **节点数**: 3 个工艺节点
- **适用场景**: 板带材大产线，追求高产能与高表面质量
- **优势**: 高效率、高表面质量、减少中间库存
- **劣势**: 对连铸质量要求高

**主要工序**:
1. 连铸（板坯）
2. 再加热炉
3. 热轧机组（粗轧→精轧→在线热处理）

## 使用步骤

### 1. 访问工艺流程页面
```
http://localhost:3000/dashboard/workflow
```

### 2. 选择工艺流程
- 点击页面右上角的 **工艺流程选择器**（下拉菜单）
- 从 6 种工艺路线中选择目标工艺
- 页面会自动加载该工艺的流程图和节点数据

### 3. 查看工艺描述
- 页面头部显示当前工艺的详细描述
- 显示适用场景和碳排放范围
- 实时更新统计信息（节点数、设备数、碳排放）

### 4. 查看流程图
- **流程视图**: 可视化展示完整工艺流程
- **列表视图**: 列表形式查看所有工艺节点
- **缩放控制**: 使用 +/- 按钮调整流程图缩放（50%-150%）

### 5. 查看节点详情
- 点击流程图中的任意节点
- 右侧面板显示节点详细信息：
  - 工艺参数（温度范围、停留时间等）
  - 能耗数据（电耗、燃料耗、气耗）
  - 物料损失率
  - 标准值和范围

## 技术实现

### 数据文件
- **主数据文件**: `frontend/lib/constants/steelProcessTemplates.ts`
- **类型定义**: `frontend/lib/types/workflow.ts`

### 核心接口
```typescript
interface ProcessTemplate {
    id: string;                         // 工艺流程ID
    name: string;                       // 工艺名称
    description: string;                // 描述
    applicability: string;              // 适用场景
    co2Range: { min: number; max: number }; // 碳排放范围
    nodes: ProcessNode[];               // 工艺节点列表
    edges: ProcessEdge[];               // 节点连线列表
}
```

### 组件架构
```
page.tsx (主页面)
├── 状态管理: selectedTemplate, selectedNode, viewMode, zoom
├── 工艺流程选择器 (Select)
├── 统计信息展示 (Badges)
└── 主内容区
    ├── ProcessFlowChart (流程图组件)
    └── NodeDetailPanel (节点详情面板)
```

## 最佳实践

### 1. 根据场景选择合适的工艺流程
- **大型综合钢厂**: 选择 **BF-BOF 长流程**
- **中小型钢厂/废钢丰富区域**: 选择 **EAF 短流程**（低碳）
- **追求低碳排放**: 选择 **DRI-EAF** 或 **EAF**
- **高端特种钢**: 选择 **真空/特殊精炼路线**
- **板带材产线**: 选择 **CC-HSM 一体线**

### 2. 对比不同工艺
- 切换工艺流程，对比节点数量
- 对比碳排放数据
- 对比关键参数（温度、能耗、物料损失）

### 3. 深入了解工艺节点
- 点击节点查看详细参数
- 关注能耗数据和物料损失率
- 查看标准值和范围

### 4. 使用缩放和视图切换
- 流程图视图：适合整体浏览
- 列表视图：适合快速定位
- 缩放控制：调整流程图大小以获得最佳视野

### 5. 关注碳排放信息
- 页面右上角显示当前工艺的吨钢碳排放范围
- 对比不同工艺的碳排放，助力低碳决策

## 故障排查

### 问题：切换工艺流程后节点未更新
**解决方案**:
1. 刷新页面
2. 检查浏览器控制台是否有 JavaScript 错误

### 问题：流程图显示不完整
**解决方案**:
1. 调整缩放比例
2. 尝试切换到列表视图
3. 检查浏览器窗口大小

### 问题：节点点击无反应
**解决方案**:
1. 确认点击的是节点卡片而非连线
2. 检查浏览器控制台是否有错误
3. 刷新页面清除缓存
