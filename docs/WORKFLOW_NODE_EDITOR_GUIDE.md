# 工艺流程节点编辑功能使用指南

## 功能概述

工艺流程管理系统现已支持 **节点的增删改** 功能，用户可以自由编辑工艺流程，添加、修改或删除工艺节点，并通过可视化对话框管理节点的工艺参数。

## 核心功能

### 1. 编辑模式
- 🔓 **进入编辑模式**：点击页面右上角"编辑模式"按钮
- ✏️ **编辑工艺流程**：自由添加、修改、删除节点
- 💾 **保存修改**：保存自定义工艺流程
- 🔄 **重置编辑**：放弃所有修改，恢复到原始模板
- 🔒 **退出编辑**：退出编辑模式，返回只读视图

### 2. 节点管理
- ➕ **添加节点**：通过对话框添加新的工艺节点
- ✏️ **编辑节点**：修改节点名称、类型、描述和工艺参数
- 🗑️ **删除节点**：删除不需要的工艺节点
- 📊 **工艺参数管理**：为每个节点添加、编辑、删除工艺参数

### 3. 工艺参数编辑
- 📝 **参数名称**：如"温度"、"压力"、"流量"等
- 📏 **标准值**：参数的标准值或范围（如"1600-1650"）
- 🔢 **单位**：参数单位（如"℃"、"MPa"、"m³/min"）
- ➕ **批量添加**：可添加多个工艺参数
- 🗑️ **批量删除**：可删除不需要的参数

## 使用步骤

### 一、进入编辑模式

1. **访问工艺流程页面**：
   ```
   http://localhost:3000/dashboard/workflow
   ```

2. **选择工艺流程模板**（可选）：
   - 从下拉菜单选择一个工艺流程作为基础
   - 如"高炉—转炉（BF→BOF）长流程"

3. **点击"编辑模式"按钮**：
   - 位置：页面右上角
   - 进入编辑模式后，界面会显示：
     - ✨ "编辑中" 标签（动画闪烁）
     - 🔄 "重置" 按钮
     - 💾 "保存" 按钮
     - ❌ "退出编辑" 按钮

---

### 二、添加工艺节点

#### 方法一：通过工具栏添加

1. **点击"添加节点"按钮**：
   - 位置：左侧工具栏（视图切换器旁边）
   - 图标：➕ 加号

2. **填写节点信息**（对话框）：

   **基本信息**：
   - **节点名称** *（必填）：如"转炉炼钢"、"电弧炉熔炼"
   - **节点类型**：
     - 工艺流程
     - 设备
     - 检验点
     - 物料
   - **描述**：简要描述该节点的功能和作用
   - **位置 X**：节点在流程图中的水平位置（像素）
   - **位置 Y**：节点在流程图中的垂直位置（像素）

3. **添加工艺参数**：

   点击"添加参数"按钮，为节点添加工艺参数：

   | 字段 | 说明 | 示例 |
   |-----|------|------|
   | **参数名称** | 参数的名称 | 温度、压力、振动、湿度 |
   | **标准值** | 标准值或范围 | 1600-1650、≥235、<50 |
   | **单位** | 参数单位 | ℃、MPa、ppm、% |

   **示例参数**：
   ```
   参数名称：温度
   标准值：1600-1650
   单位：℃

   参数名称：氧气流量
   标准值：500
   单位：m³/t

   参数名称：终碳含量
   标准值：0.02-0.2
   单位：%
   ```

4. **保存节点**：
   - 点击"添加节点"按钮
   - 节点会立即出现在流程图中

---

### 三、编辑现有节点

#### 方法一：列表视图编辑

1. **切换到列表视图**：
   - 工具栏选择"列表视图"

2. **点击节点右侧的编辑按钮**：
   - 图标：✏️ 铅笔

3. **修改节点信息**：
   - 在对话框中修改节点名称、类型、描述
   - 添加、删除或修改工艺参数

4. **保存修改**：
   - 点击"保存修改"按钮

#### 方法二：详情面板编辑

1. **选择节点**：
   - 在流程图或列表视图中点击节点

2. **点击"编辑节点"按钮**：
   - 位置：右侧详情面板顶部
   - 图标：✏️ 编辑节点

3. **修改节点信息并保存**

---

### 四、删除工艺节点

#### 方法一：列表视图删除

1. **切换到列表视图**

2. **点击节点右侧的删除按钮**：
   - 图标：🗑️ 垃圾桶（红色）

3. **确认删除**：
   - 系统会弹出确认对话框
   - 点击"确定"删除节点

#### 方法二：详情面板删除

1. **选择节点**

2. **点击"删除节点"按钮**：
   - 位置：右侧详情面板顶部
   - 颜色：红色

3. **确认删除**

⚠️ **注意**：
- 删除节点会同时删除所有连接到该节点的连线
- 删除操作不可撤销（除非点击"重置"按钮）

---

### 五、保存和重置

#### 保存修改

1. **点击"保存"按钮**：
   - 位置：页面右上角
   - 图标：💾 保存

2. **确认保存**：
   - 系统会显示保存成功提示
   - 自动退出编辑模式

#### 重置编辑

1. **点击"重置"按钮**：
   - 位置：页面右上角
   - 图标：🔄 重置

2. **确认重置**：
   - 系统会弹出确认对话框
   - 点击"确定"放弃所有修改
   - 恢复到原始模板数据

#### 退出编辑

1. **点击"退出编辑"按钮**：
   - 位置：页面右上角
   - 直接退出编辑模式
   - ⚠️ 未保存的修改会丢失

## 使用场景示例

### 场景 1：基于模板创建自定义流程

**目标**：基于"废钢电炉（EAF）短流程"，添加一个"真空脱气"节点

**步骤**：
1. 选择"废钢电炉（EAF）短流程"模板
2. 点击"编辑模式"
3. 点击"添加节点"
4. 填写节点信息：
   - 节点名称：真空脱气（VD）
   - 节点类型：工艺流程
   - 描述：真空炉脱气、降低O/H/N含量
   - 位置：X=850, Y=250
5. 添加工艺参数：
   - 温度：1400-1650 ℃
   - 时间：15-60 分钟
   - 氧含量：<10 ppm
   - 氢含量：<1-2 ppm
6. 点击"添加节点"
7. 点击"保存"

### 场景 2：修改现有节点参数

**目标**：修改"转炉炼钢"节点的温度参数

**步骤**：
1. 进入编辑模式
2. 选择"转炉炼钢"节点
3. 点击右侧"编辑节点"按钮
4. 在对话框中找到"温度"参数
5. 修改标准值：从"1550-1700"改为"1600-1680"
6. 点击"保存修改"
7. 点击"保存"

### 场景 3：删除不需要的节点

**目标**：删除"炼焦（焦炉）"节点（改用外购焦炭）

**步骤**：
1. 进入编辑模式
2. 切换到"列表视图"
3. 找到"炼焦（焦炉）"节点
4. 点击右侧删除按钮 🗑️
5. 确认删除
6. 点击"保存"

## 技术细节

### 数据结构

**节点数据结构**：
```typescript
interface ProcessNode {
    id: string;                         // 节点ID（唯一标识）
    name: string;                       // 节点名称
    type: "process" | "equipment" | "inspection" | "material";
    description: string;                // 描述
    position: { x: number; y: number }; // 位置
    status?: "normal" | "warning" | "error" | "optimizing";
    parameters?: ProcessParameter[];    // 工艺参数列表
}
```

**工艺参数结构**：
```typescript
interface ProcessParameter {
    name: string;                       // 参数名称
    standardValue: string | number;     // 标准值
    unit: string;                       // 单位
    actualValue?: string | number;      // 实际值（可选）
    range?: { min: number; max: number }; // 范围（可选）
    isOutOfRange?: boolean;             // 是否超出范围（可选）
}
```

### 状态管理

**编辑模式状态**：
- `isEditMode`: 是否处于编辑模式
- `customNodes`: 自定义节点列表
- `customEdges`: 自定义连线列表
- `isEditorOpen`: 编辑对话框是否打开
- `editorMode`: 编辑模式（"add" | "edit"）
- `editingNode`: 正在编辑的节点

### 数据流

```
用户操作
   ↓
编辑模式 → 克隆模板数据到 customNodes/customEdges
   ↓
添加/编辑/删除节点
   ↓
更新 customNodes/customEdges
   ↓
保存 → 提示成功（可扩展为保存到数据库）
   ↓
退出编辑模式
```

## 注意事项

### ⚠️ 数据安全

1. **编辑模式独立**：
   - 编辑模式使用独立的数据副本
   - 不会影响原始模板数据
   - 点击"重置"可恢复原始数据

2. **保存确认**：
   - 保存前系统会显示确认提示
   - 包含修改的节点数量

3. **删除确认**：
   - 删除节点前系统会弹出确认对话框
   - 删除操作会同时删除相关连线

### 💡 最佳实践

1. **合理命名**：
   - 使用清晰、描述性的节点名称
   - 避免使用"节点1"、"节点2"等模糊名称

2. **详细参数**：
   - 为每个节点添加关键工艺参数
   - 包含标准值和单位
   - 便于后续分析和优化

3. **逻辑位置**：
   - 合理安排节点的X/Y位置
   - 保持流程图的可读性
   - 建议按工序顺序从左到右排列

4. **定期保存**：
   - 完成一组修改后及时保存
   - 避免长时间编辑后丢失数据

5. **使用重置**：
   - 如果修改出错，可以使用"重置"功能
   - 重新开始编辑

## 故障排查

### 问题：对话框无法打开
**解决方案**：
1. 刷新页面
2. 检查浏览器控制台是否有JavaScript错误
3. 确认已进入编辑模式

### 问题：保存后数据丢失
**原因**：当前版本保存在前端内存中，刷新页面会丢失

**解决方案**：
1. 编辑过程中避免刷新页面
2. 使用"重置"功能恢复原始数据
3. 未来版本会支持数据库持久化

### 问题：节点位置不合适
**解决方案**：
1. 编辑节点，修改位置X/Y值
2. 建议值：
   - X: 100-2000（流程图宽度范围）
   - Y: 100-500（流程图高度范围）
3. 节点之间保持250-300像素间距
