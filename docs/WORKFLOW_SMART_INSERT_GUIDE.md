# 工艺流程智能节点插入指南

## 📖 功能概述

智能节点插入功能允许用户在工艺流程图中的任意位置添加新节点，系统会自动计算节点坐标并建立连接关系，无需手动输入复杂的坐标值。

---

## ✨ 核心特性

### 1. 四种插入位置

| 插入位置 | 说明 | 自动操作 |
|---------|------|---------|
| **在流程开头** | 新节点成为第一个节点 | 自动创建：新节点 → 原第一个节点 |
| **在流程末尾** | 新节点成为最后一个节点 | 自动创建：原最后节点 → 新节点 |
| **在指定节点之前** | 插入到指定节点前面 | 自动调整：A → B → C 变为 A → **新节点** → B → C |
| **在指定节点之后** | 插入到指定节点后面 | 自动调整：A → B → C 变为 A → B → **新节点** → C |

### 2. 自动计算坐标

系统会根据插入位置自动计算新节点的坐标：
- **开头/末尾**：根据第一个/最后一个节点位置偏移 200 像素
- **之前/之后**：精确计算在前后节点的中间位置

### 3. 智能连线管理

- ✅ 自动创建新节点的输入/输出连线
- ✅ 自动删除被替换的旧连线
- ✅ 保持流程图的连续性和一致性

### 4. 自动布局优化 ✨

插入或删除节点后，系统会自动刷新布局：
- **层次分明**：根据连接关系自动分层（拓扑排序）
- **间距均匀**：水平间距 250px，垂直间距 150px
- **垂直居中**：同一层级的节点自动对齐
- **连线整洁**：最大程度避免连线交叉和重叠

**手动刷新布局**：
- 点击工具栏的 "刷新布局" 按钮 🔄
- 一键优化整个流程图

## 🚀 使用步骤

### 第一步：进入编辑模式

1. 访问工艺流程页面：`http://localhost:3000/dashboard/workflow`
2. 点击页面右上角的 **"编辑模式"** 按钮
3. 系统会克隆当前工艺流程数据，准备编辑

### 第二步：打开添加节点对话框

点击工具栏中的 **"添加节点"** 按钮 ➕

### 第三步：填写基本信息

<details>
<summary><strong>1. 节点名称</strong>（必填）</summary>

**示例**：
- `预热炉`
- `脱硫工序`
- `质量检测点`
- `成品包装`

</details>

<details>
<summary><strong>2. 节点类型</strong></summary>

**可选类型**：
- 🏭 **工艺流程** (process) - 主要生产工序
- ⚙️ **设备** (equipment) - 关键设备
- 🔍 **检验点** (inspection) - 质量检查
- 📦 **物料** (material) - 原料或中间品

</details>

<details>
<summary><strong>3. 描述</strong></summary>

**示例**：
```
功能：预热原料至800-900℃
作用：提高后续工序效率，减少能耗
注意事项：温度均匀性控制
```

</details>

### 第四步：选择插入位置 ⭐

这是最关键的一步！

#### 选项 1：在流程开头

```
插入前：  [原料准备] → [烧结] → [高炉炼铁]
插入后：  [预热炉] → [原料准备] → [烧结] → [高炉炼铁]
          ↑ 新节点
```

**适用场景**：
- 添加前置工序（如原料预处理）
- 添加质量检查点（在生产开始前）

#### 选项 2：在流程末尾

```
插入前：  [轧制] → [退火] → [成品检验]
插入后：  [轧制] → [退火] → [成品检验] → [包装入库]
                                         ↑ 新节点
```

**适用场景**：
- 添加后续工序（如包装、存储）
- 添加最终检验环节

#### 选项 3：在指定节点之前

**步骤**：
1. 选择 **"在指定节点之前"**
2. 从下拉菜单中选择目标节点（如"烧结"）
3. 系统提示：`新节点将添加在"烧结"之前`

```
插入前：  [原料准备] → [烧结] → [高炉炼铁]
插入后：  [原料准备] → [筛分工序] → [烧结] → [高炉炼铁]
                       ↑ 新节点
```

**适用场景**：
- 在现有工序前增加准备步骤
- 插入额外的质量检查点

#### 选项 4：在指定节点之后

**步骤**：
1. 选择 **"在指定节点之后"**
2. 从下拉菜单中选择目标节点（如"转炉炼钢"）
3. 系统提示：`新节点将添加在"转炉炼钢"之后`

```
插入前：  [转炉炼钢] → [连续铸造]
插入后：  [转炉炼钢] → [脱硫精炼] → [连续铸造]
                       ↑ 新节点
```

**适用场景**：
- 在现有工序后增加后处理步骤
- 细化工艺流程

### 第五步：添加工艺参数

点击 **"添加参数"** 按钮 ➕，填写：

| 字段 | 说明 | 示例 |
|-----|------|------|
| **参数名称** | 工艺参数的名称 | `温度`、`压力`、`时间` |
| **标准值** | 参考值或范围 | `800-900`、`≥2.5`、`30-45` |
| **单位** | 参数单位 | `℃`、`MPa`、`分钟` |

**示例参数**：
```
参数1: 温度 | 1200-1400 | ℃
参数2: 停留时间 | 20-30 | 分钟
参数3: Fe含量 | 55-60 | %
```

### 第六步：保存节点

点击对话框底部的 **"添加节点"** 按钮。

系统会自动：
- ✅ 计算新节点的 X、Y 坐标
- ✅ 创建必要的连线（edges）
- ✅ 更新流程图显示

## 💡 最佳实践

### ✅ 推荐做法

1. **先规划再添加**：
   - 明确新工序的位置和作用
   - 确定需要哪些工艺参数

2. **合理选择插入位置**：
   - 前置工序 → 选择"之前"或"开头"
   - 后续工序 → 选择"之后"或"末尾"
   - 中间工序 → 选择"之前"或"之后"

3. **详细填写参数**：
   - 至少添加 3-5 个关键参数
   - 标准值要精确（带范围或阈值）
   - 单位要规范统一

4. **及时保存**：
   - 添加多个节点后，点击"保存"按钮
   - 避免数据丢失

### ❌ 避免的做法

1. ❌ 不要连续添加多个节点不保存
2. ❌ 不要省略工艺参数
3. ❌ 不要使用模糊的节点名称（如"工序1"、"节点A"）
4. ❌ 不要忘记选择正确的插入位置

## 🔧 技术原理

### 自动布局算法

系统使用 **层次布局算法（Hierarchical Layout）** 优化节点位置：

**步骤1：构建图结构**
```typescript
// 构建邻接表和入度表
adjacency: Map<节点ID, 后继节点ID[]>
inDegree: Map<节点ID, 入度数量>
```

**步骤2：拓扑排序确定层级**
```typescript
// BFS广度优先遍历
1. 找到所有入度为0的节点（起点） → 层级0
2. 遍历每个节点，更新后继节点的层级
3. 后继节点层级 = max(当前层级, 前驱节点层级 + 1)
4. 直到所有节点都被分配层级
```

**步骤3：按层级分组**
```typescript
nodesByLevel: Map<层级, 节点[]>
// 例如：
// 层级0: [原料准备]
// 层级1: [烧结, 炼焦]
// 层级2: [高炉炼铁]
// 层级3: [转炉炼钢]
```

**步骤4：计算最终坐标**
```typescript
X坐标 = 起始X + 层级 × 水平间距（250px）
Y坐标 = 起始Y + 层内索引 × 垂直间距（150px） - 垂直居中偏移

// 垂直居中偏移 = (该层节点总数 - 1) × 垂直间距 / 2
// 确保同层节点垂直居中对齐
```

**优势**：
- ✅ 自动消除节点重叠
- ✅ 连线方向一致（从左到右）
- ✅ 层次清晰，便于理解流程
- ✅ 支持复杂的分支和合并结构

### 坐标计算逻辑（插入时的临时坐标）

```typescript
// 在开头插入
新节点.x = 第一个节点.x - 200
新节点.y = 第一个节点.y

// 在末尾插入
新节点.x = 最后节点.x + 200
新节点.y = 最后节点.y

// 在节点之间插入
新节点.x = (前一个节点.x + 后一个节点.x) / 2
新节点.y = (前一个节点.y + 后一个节点.y) / 2
```

### 连线调整逻辑

**在 A 和 B 之间插入 X**：
1. 查找 A → B 的连线
2. 删除 A → B 连线
3. 创建 A → X 连线
4. 创建 X → B 连线

**在开头插入 X**：
1. 查找第一个节点 A
2. 创建 X → A 连线

**在末尾插入 X**：
1. 查找最后一个节点 Z
2. 创建 Z → X 连线

## 🐛 常见问题

### Q1：添加节点后看不到新节点？

**解决方案**：
- 检查是否已保存（点击"保存"按钮）
- 调整缩放比例（使用 + / - 按钮）
- 切换到列表视图确认节点已添加

### Q2：新节点位置不合适？

**解决方案**：
- 方法1：删除节点，重新添加并选择正确的插入位置
- 方法2：使用"编辑节点"功能（未来支持拖拽调整）

### Q3：连线没有自动创建？

**检查**：
- 确认插入位置选择正确
- 检查目标节点是否存在
- 尝试删除节点重新添加

### Q4：参数过多时对话框显示不完整？

**解决方案**：
- 对话框内容区域支持滚动
- 向下滚动查看更多参数
- 底部留白足够，确保最后一个参数可见

## 📊 功能对比

| 功能 | 手动输入坐标 | 智能插入位置 | 智能插入 + 自动布局 ✨ |
|-----|------------|------------|---------------------|
| **操作难度** | ⭐⭐⭐⭐⭐ 需要计算坐标 | ⭐ 直观选择 | ⭐ 直观选择 + 自动优化 |
| **出错概率** | 高（坐标重叠、连线错误） | 低（自动计算） | **极低（智能优化）** |
| **学习成本** | 高（需理解坐标系统） | 低（自然语言选择） | 低（无需关心坐标） |
| **操作速度** | 慢（多次输入） | 快（一次选择） | **极快（一键完成）** |
| **连线管理** | 手动创建 | 自动创建 | 自动创建 |
| **布局美观度** | 差（手动调整） | 一般（简单计算） | **优秀（算法优化）** |
| **可维护性** | 差（难以调整） | 中等（需手动优化） | **优秀（自动适应）** |

## 🎓 进阶技巧

### 技巧 1：批量添加节点

如果需要添加多个节点：
1. 先添加最靠前的节点
2. 再添加后续节点（使用"之后"插入）
3. 最后一次性保存

### 技巧 2：参数复用

对于相似节点：
1. 先创建第一个节点（完整参数）
2. 编辑新节点时，参考第一个节点的参数
3. 复制标准值和单位（手动）

### 技巧 3：流程优化

添加节点后检查：
- ✅ 节点顺序是否符合实际工艺流程
- ✅ 连线是否正确连接
- ✅ 参数是否完整合理

### 技巧 4：利用自动布局 ✨

**场景1：批量添加后优化**
1. 连续添加多个节点
2. 点击"刷新布局"按钮
3. 系统自动优化所有节点位置

**场景2：复杂流程清理**
- 流程图混乱时，一键刷新布局
- 自动消除重叠和交叉
- 恢复层次结构

**场景3：布局微调**
- 自动布局后，个别节点位置不满意
- 未来可通过拖拽微调（待开发）
- 当前可重新添加节点
