# 钢铁行业专业词汇增强指南

## 概述

本指南介绍如何为RAG Agent系统添加钢铁行业专业词汇，让AI助手在问答时能够识别和使用专业术语。

## 功能特点

✅ **专业词汇库**: 包含218个钢铁行业专业术语  
✅ **多语言支持**: 中英文对照术语  
✅ **分类管理**: 8大类别，涵盖钢种、工艺、设备等  
✅ **自动增强**: 一键为所有Agent添加专业词汇

## 使用方法

### 一键增强（推荐）

```bash
# 运行增强脚本
python -m scripts.enhance_steel_vocabulary
```

脚本会自动：
- 为所有Agent创建包含专业词汇的增强prompt
- 支持中英文双语
- 标记增强状态和统计信息

### 手动编辑

1. **访问管理界面**
   - 登录系统后进入Admin面板
   - 选择"Prompt管理"
   - 找到对应的Agent和语言

2. **编辑Prompt内容**
   - 在现有prompt基础上添加专业词汇部分
   - 参考`scripts/enhance_steel_vocabulary.py`中的模板

## 自定义词汇

### 添加新术语

1. **编辑词汇库文件**
   ```python
   # scripts/enhance_steel_vocabulary.py
   STEEL_VOCABULARY = {
       "steel_grades": {
           "zh": ["Q235", "Q345", "你的新术语"],
           "en": ["Q235", "Q345", "Your New Term"]
       }
   }
   ```

2. **重新运行增强脚本**
   ```bash
   python -m scripts.enhance_steel_vocabulary
   ```

## 故障排除


2. **检查数据库**
   ```sql

   ```
